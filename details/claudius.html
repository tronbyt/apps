Claudius

Live Claude usage stats

Companion display for Claudius, the macOS menu bar app that monitors Claude Code and Claude.ai usage. Install Claudius from github.com/NSLuke/Claudius and point it at your Tronbyt — it pushes live cost, token, session, and weekly usage frames to this app's installation. Without the Mac companion installed, this app shows a placeholder.
