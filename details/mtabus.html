MTA Bus

MTA bus stop tracker

>- Track the arrival time for MTA buses. * Requires an MTA Bus Time API key and MTA bus stop ID. You can request an API key at this URL: https://register.developer.obanyc.com/ * You also need to set a bus stop ID. It should be a 6-digit number. * Look it up at: https://bustime.mta.info/m/routes/ * Enjoy!

By Kevin Eder
