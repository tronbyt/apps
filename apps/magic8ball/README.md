# Magic 8 Ball for Tronbyt
Roll one of 20 classic Magic 8 Ball answers. Good luck!

This app supports 2x and 64x64 displays. You can also customize the app's background color.

![Magic 8 Ball for Tronbyt](magic_8_ball.webp)

## Possible answers
There are 20 possible answers in the classic Magic 8 Ball. You can see all the possible answers [here](https://en.wikipedia.org/wiki/Magic_8_Ball#Possible_answers).
