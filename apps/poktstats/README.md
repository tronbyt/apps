# POKT Stats applet for Tronbyt

Displays the current USD price of the POKT token from [CoinGecko](https://www.coingecko.com/en/coins/pocket-network), and the latest block height of Pocket Network's Shannon mainnet from [Polkachu](https://polkachu.com)'s public RPC node. The block height is updated every 10 minutes and the price every 30 minutes. No API key required. [POKT](https://www.pokt.network) is a decentralized network that provides RPC access to the most popular Web3 systems and chains.
