# Trivia Applet for Tronbyt

Displays a random trivia question with its category and difficulty, then the answer.

Questions come from [Open Trivia DB](https://opentdb.com), used under the [Creative Commons Attribution-ShareAlike 4.0 licence](https://creativecommons.org/licenses/by-sa/4.0/). The app originally used jService, which has closed.
